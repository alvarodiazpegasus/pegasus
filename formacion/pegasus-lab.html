Acerca de

Demo interna · Fundación Pegasus. Cada bloque es una pieza reutilizable. Todo se puede combinar para construir una dinámica.

El catálogo completo de lo que podemos hacer

Esto es un escaparate, no una dinámica. Cada bloque demuestra UNA capacidad — luego se ensamblan para construir cosas como El Canto de Lila. Pulsa, arrastra, juega con todo: lo que ves aquí es lo que podemos meter en cualquier SCORM de TPT, IS o Indiferente.
